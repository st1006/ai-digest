# Промпт: обзор руководства CMIT Solutions по zero-trust AI governance

## Контекст

Блог «Генеративный ИИ в бизнесе» для собственников SMB, руководителей отделов и специалистов по внедрению. Аудиторию волнуют окупаемость, выбор инструментов без команды ML, риски и реальные кейсы. Формальный стиль: деловой тон, третье лицо, без разговорных оборотов.

## Задача

Напиши обзор руководства CMIT Solutions по zero-trust AI governance для SMB. Ключевой тезис: каждый ИИ-инструмент, который использует компания — это потенциальная точка атаки, утечки данных или сбоя комплаенса. Источник: CMIT Solutions Zero-Trust AI Governance Guide (февраль 2026).

## Формат

- 300 слов. Заголовок + 2 подзаголовка. Markdown.

## Ограничения

- Третье лицо («компания выпустила», не «мы выпустили»).
- Без разговорных оборотов.
- Без маркетинга.
- Без эмодзи.
