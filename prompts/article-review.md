# Промпт: обзор исследования или новости

## Контекст

Блог «Генеративный ИИ в бизнесе» для собственников SMB, руководителей отделов и специалистов по внедрению. Аудиторию волнуют окупаемость, выбор инструментов без команды ML, риски и реальные кейсы. Маркетинговый шум и код исключены.

Формат — краткий обзор одной новости или исследования.

## Задача

Напиши обзор исследования [НАЗВАНИЕ ИССЛЕДОВАНИЯ] ([дата публикации]).

Ключевые данные из исследования:
- [Факт 1 с цифрой]
- [Факт 2 с цифрой]
- [Факт 3 с цифрой]

Краткий пересказ: о чем исследование, какие цифры важны для SMB, что это значит для принятия решений.

## Формат

- 300–500 слов.
- Заголовок: до 80 символов, конкретный, без общих слов.
- 2 подзаголовка.
- Markdown, без HTML.
- Ссылка на источник в конце.

## Ограничения

- Без маркетинговых фраз («революционный», «прорывной», «меняет правила игры»).
- Только факты и цифры из исследования — без оценочных суждений.
- Не добавляй выводы «это изменит индустрию».
- Не пиши от первого лица.
- Без кода и сложной терминологии.
